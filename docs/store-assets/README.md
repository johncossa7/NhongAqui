# Play Store assets

Assets prepared for the Google Play listing:

- `play-store-icon.png`: 512 x 512 PNG generated from the production app icon.
- `feature-graphic.png`: 1024 x 500 PNG using the production brand.

Still required after installing the signed Android build:

- At least two real Android phone screenshots. Recommended set: discovery, product details, publishing and messages.

Do not use Expo Go screenshots in the public listing.
